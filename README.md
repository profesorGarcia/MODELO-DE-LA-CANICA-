# MODELO-DE-LA-CANICA-
El modelo integra conceptos como la fuerza gravitacional, las órbitas, la energía orbital específica, el momento angular y la relación entre velocidad y distancia. Incluye las ecuaciones fundamentales de la mecánica celeste, como la energía orbital específica ε = v²/2 − GM/r y el momento angular específico h = r v⊥.
